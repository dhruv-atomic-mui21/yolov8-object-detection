# Notebooks directory

This folder contains Jupyter notebooks for exploration and demonstration.

## Available Notebooks

### exploration.md (Notebook Template)
Interactive notebook for:
- Loading and testing the YOLOv7 detector
- Running inference on images and videos
- Performance benchmarking
- Visualization examples

## Converting to Jupyter Notebook

If you have jupytext installed, you can convert the markdown to a notebook:

```bash
pip install jupytext
jupytext --to notebook exploration.md
```

Or simply copy the code cells into a new Jupyter notebook.

## Running Notebooks

```bash
# Install Jupyter
pip install jupyter

# Start Jupyter Lab
jupyter lab

# Or classic notebook
jupyter notebook
```
